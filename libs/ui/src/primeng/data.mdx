# Data

  <Story of={Stories.Status} />

Theme proof for PrimeNG data display. Prefer `pds-list` over stock `p-tree` for journey and document lists. Prefer `c-skeleton-slot` when a skeleton needs a sized wrapper.

What Plectrum changes: [Skeleton Slot](?path=/docs/docs-primeng-customizations--docs#structural-restyles-06-components) and [Timeline content-only](?path=/docs/docs-primeng-customizations--docs#structural-restyles-06-components). Table and Tree stay stock.

## Endorsed composition

- Sortable tables use `pSortableColumn` + `p-sortIcon` — no custom header chrome
- Document / journey lists use [List](?path=/docs/custom-components-list--docs), not a restyled `p-tree`
- Loading placeholders use [Skeleton Slot](?path=/docs/custom-components-skeleton-slot--docs) when the slot has a known size; stock `p-skeleton` is fine for inline lines
- Timeline with no opposite column uses `c-timeline--content-only` — see [Timeline](?path=/docs/custom-components-timeline--docs)

Figma: [DataTable](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-?node-id=6738-49721) · [Tree](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-?node-id=6738-49728) · [Skeleton](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-?node-id=6738-55113) · [Timeline](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-?node-id=6738-49727)
