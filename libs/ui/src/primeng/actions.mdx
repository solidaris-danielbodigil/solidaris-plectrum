# Actions

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

Theme proof for PrimeNG actions. Plectrum styles `p-button`, `p-togglebutton` and `p-selectbutton` through `providePlectrum()` — there is no Angular wrapper.

What Plectrum changes: none for this family. Buttons stay [deliberately stock](?path=/docs/docs-primeng-customizations--docs#deliberately-stock).

## Endorsed composition

- Icons are Bootstrap Icons (`bi bi-*`), never PrimeIcons
- Prefer `size="small"` in toolbars; default size on page actions
- Use `severity` for meaning, not custom colours

Figma: [Button](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-?node-id=6738-49717) · [ToggleButton](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-?node-id=6738-46435) · [SelectButton](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-?node-id=6738-46433)

API: [primeng.org/button](https://primeng.org/button) · [togglebutton](https://primeng.org/togglebutton) · [selectbutton](https://primeng.org/selectbutton)
