## Default

The placeholder is the action. Nothing is selected until the person chooses.

<Canvas of={Stories.Default} />
<Controls of={Stories.Default} />

## When to use

Use Select for one value from a known list of four or more: a mutualité, a country, a status.

- Two or three short options: [SelectButton](?path=/docs/primeng-selectbutton--docs).
- The person types toward a long list: [AutoComplete](?path=/docs/primeng-autocomplete--docs).
- Several values: [MultiSelect](https://primeng.org/multiselect). That control is not documented here yet.

Select belongs to the [Forms](?path=/docs/primeng-forms--docs) family and sits inside [Form Field](?path=/docs/custom-components-form-field--docs).

## Variants

**Placeholder.** Do not pre-select a value the person did not choose, unless there is only one sensible default.

<Canvas of={Stories.Default} />

**Filter.** Turn the filter on when the list has more than about ten entries. Always set `appendTo="body"` so the panel is not clipped. `fluid` fills the column. `size="small"` is for a toolbar.

<Canvas of={Stories.Filtered} />

## Content

The placeholder is the action: Choisissez une mutualité. Options are nouns in the language of the screen, in the order the person expects.

## Behavior

Enter or Space opens the list. Arrows move. Enter chooses. Escape closes and returns focus to the field. Typing while the list is open jumps to a match.

## Accessibility

Form Field links the label through `inputId`. The application provides the label, the option text and the placeholder.
