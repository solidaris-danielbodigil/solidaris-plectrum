# Content and navigation

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

Theme proof for PrimeNG content and navigation primitives.

What Plectrum changes: [Card title spacing](?path=/docs/docs-primeng-customizations--docs#structural-restyles-06-components) and [Tag icon line-height](?path=/docs/docs-primeng-customizations--docs#structural-restyles-06-components). Badge, Message, Divider, Breadcrumb, Tabs, Stepper and ScrollTop stay stock.

## Endorsed composition

- Icons are Bootstrap Icons (`bi bi-*`)
- Status meaning uses Tag / Message `severity`, not custom colours
- Tabs in iSHARE category toolbars may add `c-affiliate-details__category-tabs` — that bridge is app-owned, see [PrimeNG customizations](?path=/docs/docs-primeng-customizations--docs)
