# Overlays

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

Theme proof for PrimeNG overlays. Every overlay in an app **must** use `appendTo="body"` so it is not clipped by `overflow` on a flex column or card.

What Plectrum changes: [Drawer width tokens and `c-drawer` shell](?path=/docs/docs-primeng-customizations--docs#structural-restyles-06-components). Dialog, Popover, Toast, Tooltip and Menu stay stock. Feature drawers compose the [Drawer](?path=/docs/custom-components-drawer--docs) shell inside `p-drawer` `#headless`.

## Endorsed composition

- `appendTo="body"` on Dialog, Drawer, Popover, Select, DatePicker, AutoComplete, Toast
- No `styleClass` on `p-drawer` / `p-dialog` roots
- Icons are Bootstrap Icons
- Toast is a singleton near the app root; do not mount one per feature
