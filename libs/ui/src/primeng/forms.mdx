# Forms

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

Theme proof for PrimeNG form controls. Labels, hints and errors belong on `pds-form-field` — do not reimplement FloatLabel unless the design calls for a floating label.

What Plectrum changes: [AutoComplete chip sizing](?path=/docs/docs-primeng-customizations--docs#structural-restyles-06-components) in `_components.autocomplete.scss`. Inputs, Select and DatePicker stay stock.

## Endorsed composition

- Wrap every labelled control in `pds-form-field` with a matching `inputId`
- Overlays (`p-select`, `p-autocomplete`, `p-datepicker`) use `appendTo="body"`
- Icons are Bootstrap Icons inside `p-iconfield` / `p-inputicon`
- Prefer `size="small"` in toolbars; `fluid` when the field should fill its column
