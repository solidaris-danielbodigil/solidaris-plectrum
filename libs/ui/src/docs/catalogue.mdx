# Find a component

PrimeNG controls, Plectrum components and CSS blocks in one list. Search by what you need to do: `error` finds Form Field, `side panel` finds Drawer.

<Unstyled>
  <Story of={Figures.Index} />
</Unstyled>

**Scope** tells you who can use a component:

- **Core** — every application.
- **Candidate** — owned by one team; its name links to that team's preview. Do not import it; propose it instead.
- **App-specific** — one product's component. Read it for ideas, do not import it.
- **Local** — built by a team in its own repository and listed by its usage report. A **Reuse likely** or **Reuse possible** tag is the team's own estimate. If you need the same thing, talk to that team before building your own.

**Used in** lists the applications that reported using a component. A demo app in this repository reads `iSHARE demo`, and `(stale)` flags an old report. A dash means no usage was reported, not that nobody uses it.

Some controls appear twice: once as a PrimeNG control and once as the Plectrum component built on it.
