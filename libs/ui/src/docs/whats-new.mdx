# What's new

What changed in each package version. **Released** is the version in the repository. It is not the same thing as “available from npm” — publish stays off until registry access exists. Install steps: [Build with Plectrum](?path=/docs/get-started-use-plectrum-in-an-app--docs).

Generated from the pending changesets and the package changelogs by `npm run changelog:build`. Do not edit the generated file by hand. Major is breaking, minor is a feature, patch is a fix. Process: [Releases and versioning](?path=/docs/docs-releases-and-versioning--docs).
