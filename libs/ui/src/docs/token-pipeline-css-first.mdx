# CSS-first surface

Component authors use **`var(--pds-*)`** and BEMIT classes (`o-*`, `c-*`, `u-*`). No other token API is available to them. The PrimeNG preset TypeScript is generated and validated, not edited; it emits custom properties only and owns no class names outside `.p-*`. ITCSS layering is unchanged.

This page is the developer view of the [pipeline overview](?path=/docs/docs-token-pipeline--docs). Figma transport is documented on [Figma sync](?path=/docs/docs-token-pipeline-figma-sync--docs). ITCSS layers and BEMIT mixes: [CSS architecture](?path=/docs/docs-css-architecture--docs). Agents and component contracts: [AI strategy](?path=/docs/docs-ai-strategy--docs). Live swatches are Angular stories under **Foundations**, because `--p-*` exists only after `providePlectrum()` boots.

## Hybrid colour tokens

A mapped colour token has two sources: the **live PrimeNG preset** (v0.6 or v1, selected in the toolbar) and the **Figma literal** generated from `tokens.json`. The custom property reads the live value and falls back to the literal. Neither value is typed by hand.

Properties of this rule:

- Aliasing is safe before Angular bootstraps: the fallback literal renders until the preset is applied.
- Toggling v0.6 ↔ v1 in the toolbar changes aliased colour swatches; foundation literals do not change.
- `alias-map.json` is reviewed. A missing entry emits a literal. CI fails if a mapped `--p-*` is never emitted by the resolved v1 preset, and warns when a `--pds-color-*` shares a `tokens.json` node with an unmapped `--p-*`.

## Reference

### Prefix migration

Completed before generation, so application repositories never inherit bare `--spacing-*` / `--text-*` / `--font-*` names.

- Declarations in spacing, typography and grid settings are `--#{$pds-prefix}-*` (`--pds-*`), including `--base-unit`, `--spacingUnit` (now `--pds-spacing-unit`), `--letter-spacing-*` and `--grid-cols`.
- `_settings.legacy-aliases.scss` redeclares the old bare names as `var(--pds-*)` and is `@forward`ed **last** in `_settings.core.scss`. Removal after one release.
- `$spacing-scale` keys are unchanged; BEM class names such as `o-layout--gap-2` are unchanged.
- `tokens:check-prefix` rejects new `--spacing-` / `--text-` / `--font-` / `--line-height-` **declarations** outside the legacy file.
