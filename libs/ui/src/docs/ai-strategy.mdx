# AI strategy

Agents work against **contracts**, not against a full-repo read. Contract-Driven Development (CDD) gives a typed metadata schema, a generated component index, and short protocols. Humans still own Figma, Storybook and the CSS.

## Definition

A **contract** is a machine-readable file next to the thing it describes. Agents load the index, then one metadata file, then a protocol. They do not invent a second design system.

## Process

How an agent is expected to work. Same order as `.ai/contracts/protocols/query-protocol.md`.

<Unstyled>
  <Story of={Figures.QueryOrder} />
</Unstyled>

The agent is the **default operator** for this flow: it scaffolds, fills the metadata, and runs the token scripts itself. Nothing here is a manual chore — `pds:component` regenerates the index when it finishes, a Cursor hook (`.cursor/hooks/regenerate-contracts-index.mjs`) re-runs `generate-index` after edits under `libs/ui`, and CI fails when the committed index is stale. Doing a step by hand stays possible; it is a choice, not a requirement.

## Reference

### Metadata file

Every `libs/ui` component has `{name}.metadata.ts` next to the class. Shape: `ComponentMetadata` in `.ai/contracts/schema/component.metadata.ts`.

<DocsTable
  headers={['Block', 'Purpose']}
  rows={[
    ['component', 'Name, category, type, path, PrimeNG wrap, BEM block, ITCSS layer, SCSS path'],
    ['usage', 'useCases, commonPatterns (with a composition snippet), antiPatterns'],
    ['variants / props', 'Inputs and option lists when the API is more than a host class'],
    ['composition', 'Slots, parents, companions, nested components'],
    ['behavior', 'States, interactions, responsive notes'],
    ['accessibility', 'Role, ARIA, keyboard, WCAG level'],
    ['tokens.consumed', '--pds-* list. Must match the stylesheet or Token contracts flags it'],
    ['tokens.primeNgMappings', 'Optional --p-* bridges this component relies on'],
    ['aiHints', 'priority, context, selectionCriteria, keywords'],
    ['examples', 'Copy-paste snippets for agents'],
  ]}
/>

Import the type from `@solidaris/contracts`. Export a const (`EmptyStateMetadata`, …). `libs/ui/src/lib/index.ts` re-exports metadata with the component.

### Index

`npm run generate-index` runs `tools/scripts/generate-index.ts`. It walks `libs/ui/src/lib`, reads imports and the colocated `.metadata.ts`, and writes `.ai/contracts/index.json`. The output is content-stable — `meta.generated` only advances when the content changed — so CI regenerates the index on every push and fails when the committed file is stale, the same pattern as the generated token files.

### Scaffold

```bash
npm run pds:component     # interactive: name, category, type, optional PrimeNG wrap
                          # regenerates .ai/contracts/index.json when it finishes
npm run generate-index    # manual run — only needed after hand-editing or deleting
```

`pds:component` creates the Angular files (no colocated stylesheet — see [CSS architecture](?path=/docs/docs-css-architecture--docs)), the `_components.{name}.scss` partial plus its `@forward` in `_components.core.scss`, a stories stub, and a `.metadata.ts` that already imports `ComponentMetadata` — then regenerates the index itself. Fill usage, tokens and aiHints before review; by default the agent does that as part of the task.
