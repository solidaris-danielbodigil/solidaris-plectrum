# Contribute

Everything ships through this repository: tokens, stylesheets, components, and this Storybook. Develop in Storybook first; applications only ever install published versions.

## Set up

```bash
git clone <repo> && cd solidaris-nx
npm install
npm run storybook     # http://localhost:6006
```

Node 18.19+, 20.11+ or 22. The apps run with `npm start` (iSHARE) and `npm run start:icrm`.

## Create a component

```bash
npm run pds:component     # name, category, type, optional PrimeNG wrap
```

The scaffolder creates the Angular files, the `.metadata.ts` contract, a stories stub, the `_components.{name}.scss` partial (forwarded from the core barrel), and regenerates `.ai/contracts/index.json`. Then:

1. Check **PrimeNG MCP** and **Figma MCP** — reuse before inventing ([CSS architecture](?path=/docs/docs-css-architecture--docs) has the authoring order).
2. Missing tokens go to `01-settings` first, cited with their Figma variable.
3. Layout is `o-flex` / `o-layout` classes in the template — never flex/gap CSS in `06-components`.
4. One story per state; the component is not done without them ([Writing stories](?path=/docs/docs-writing-stories--docs)).

By default the **agents do this work** — ask the Solidaris coordinator for a component and it runs research, tokens, implementation and QA end to end ([AI strategy](?path=/docs/docs-ai-strategy--docs)). Every command stays runnable by hand.
