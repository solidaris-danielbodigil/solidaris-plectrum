# Design with Plectrum

Design in Figma; use this Storybook to see what each component does, its variants and its states. You do not need the repository to design a screen.

Enable these four libraries. Do not draw new components on the main kit.

## When nothing fits

Draw the candidate in [PLECTRUM · Custom components](https://www.figma.com/design/IRkr21rHS0w7rI0bgrv1fZ/PLECTRUM-%C2%B7-Custom-components), then open a [proposal](https://github.com/solidaris-danielbodigil/solidaris-plectrum/issues/new?template=proposal.yml): link the frame, say which PrimeNG and Plectrum components you tried, and what the screen must do. Mention any design-team review. New token variables go on a separate branch of [Plectrum DS · PrimeNG v21](https://www.figma.com/design/wjMnb8GsK8bVKA7UreOJ4L/Plectrum-DS--PrimeNG-v21-).

Your application team can still build the component locally while Core decides whether to share it.
