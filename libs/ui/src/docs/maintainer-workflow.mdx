## Create a component

Once the core team has recorded its decision, scaffold the component. The owner is a registered team ID ({REGISTRY.teams.map((team) => team.id).join(', ')}):

<pre><code>{command('scaffold')}</code></pre>

The scaffolder creates the Angular files, the `.metadata.ts` contract with its `governance` block, a stories stub and the style partial. Then run the component check profile:

<pre><code>{profileCommands('component').join('\n')}</code></pre>

1. Check **PrimeNG MCP**, **Figma MCP**, then **Storybook MCP** when `npm run storybook` is up — reuse before inventing ([AI strategy → Storybook MCP](?path=/docs/docs-ai-strategy--docs#storybook-mcp)).
2. Missing shared tokens go to `01-settings` first, cited with their Figma variable.
3. Layout is `o-flex` / `o-layout` classes in the template — never flex/gap CSS in `06-components`.
4. One story per state; the component is not done without them ([Writing stories](?path=/docs/docs-writing-stories--docs)). Application-owned pages are titled `Patterns/{App}/…`.

A release candidate adds packing: <code>{profileCommands('release').at(-1)}</code>.

## Language

User-facing copy in `libs/ui` lives in a colocated `{name}.i18n.ts` (`fr` + `nl`). Components resolve it with `injectPdsMessages()` from the `PDS_LOCALE` token. The token factory reads Angular `LOCALE_ID` (`nl*` → `nl`, otherwise `fr`); apps can also call `providePdsLocale('nl')`. String inputs still win when the host passes them.

This Storybook has a **FR / NL** toolbar (`globals.locale`). One `Dutch` story per migrated component pins `globals: { locale: 'nl' }` and asserts a Dutch string. Terminology decisions live in `.ai/questions/nl-copy-review.md`.

## Before you commit

`npm install` installs the pre-commit hook, unless another hook is already in place. The hook runs `npm run check:commit`: docs, contracts, tokens, style lint and generated files. If it fails, fix the problem, stage any regenerated file and commit again.

`git commit --no-verify` skips the hook, but a pull request into `main` still runs every CI gate below.

Common failures:

- **Unknown `--pds-*` token** — use a published token or declare an allowed application token.
- **Metadata/API mismatch** — an Angular input and its documented prop disagree.
- **Storybook build failure** — a story, provider, style or asset cannot be bundled.

The preset-reference validation only reports (advisory). Chromatic runs only when the repository enables it.
