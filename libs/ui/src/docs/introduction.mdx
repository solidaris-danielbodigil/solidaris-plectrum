Plectrum is the Solidaris design system — shared components, tokens and layout for every application. This Storybook is the published guidance. Figma is where you design; it is not a second set of rules.

## Get help

A typo or a wrong example is a pull request. A missing component, variant or token is a [proposal](https://github.com/solidaris-danielbodigil/solidaris-plectrum/issues/new?template=proposal.yml). Say what the screen must do, what you already tried, and attach a Figma link. The core team answers: use what exists, they will build it, or your team builds it and owns it.
