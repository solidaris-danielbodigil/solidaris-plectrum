# Plectrum Design System

Plectrum is the Solidaris design system: PrimeNG components wearing a token-driven theme, a shared Angular component library, and an ITCSS stylesheet — one source of truth consumed by iSHARE and iCRM. This Storybook is its living catalogue: every page renders from the same compiled CSS the applications ship.
