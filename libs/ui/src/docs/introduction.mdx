Plectrum is the Solidaris design system — shared components, tokens and layout for every application. This Storybook documents the system. Use the documentation matching the release you install; [Releases and versioning](?path=/docs/docs-releases-and-versioning--docs) explains published releases and development previews. Figma is where you design; it is not a second set of rules.

<Unstyled>
  <Story of={Figures.Audience} />
</Unstyled>

Core components are shared. An application Candidate or App-specific component stays with its owning team; promotion to Core is a separate decision. A design-team proposal can start in Figma's Custom components file and becomes available to applications only after Core implementation and release. Plectrum component pages show status and owner — [Contribute → Status and owner](?path=/docs/get-started-contribute--docs#status-and-owner).

Each application team works in its own repository. The source starter uses `npm install` and its application-owned `postinstall` to generate local ITCSS, Storybook, tests, `.ai` guidance, editor adapters and checks. This targets the next devkit release; use versioned documentation for published packages. [Build with Plectrum](?path=/docs/get-started-use-plectrum-in-an-app--docs) gives the nine setup steps and verification criteria. [AI strategy → Team repositories](?path=/docs/docs-ai-strategy--docs#team-repositories) explains the editor integration.

A starter that prepares SCSS, empty ITCSS layers, local Storybook, tests, hooks and CI during `npm install` is [planned work](?path=/docs/get-started-use-plectrum-in-an-app--docs#planned-onboarding). Until it ships, track these setup tasks explicitly in the application's onboarding epic.

## Get help

A typo or a wrong example is a pull request. A missing component, variant or token is a [proposal](https://github.com/solidaris-danielbodigil/solidaris-plectrum/issues/new?template=proposal.yml). Say what the screen must do, what you already tried, and attach a Figma link. The core team records a decision — [Contribute → Proposal decisions](?path=/docs/get-started-contribute--docs#proposal-decisions) says what each one means and who acts next.
