Plectrum is the Solidaris design system: shared components, tokens and layout for every application. Design in Figma, build with the packages, and check this Storybook for how each piece behaves. Read the documentation of the release you install — see [Releases and versioning](?path=/docs/docs-releases-and-versioning--docs).

<Unstyled>
  <Story of={Figures.Audience} />
</Unstyled>

Core components are for every application. A component built by an application team stays with that team until Core adopts it. Each component page shows its status and owner — see [Contribute](?path=/docs/get-started-contribute--docs#status-and-owner).

Each team works in its own repository, set up from the Plectrum starter: `npm install` prepares styles, Storybook, tests, editor instructions and checks. [Build with Plectrum](?path=/docs/get-started-use-plectrum-in-an-app--docs) walks through it.

## Get help

Found a typo or a wrong example? Open a pull request. Missing a component, variant or token? Open a [proposal](https://github.com/solidaris-danielbodigil/solidaris-plectrum/issues/new?template=proposal.yml): describe what the screen must do, what you tried, and link the Figma frame. The core team answers with a [decision](?path=/docs/get-started-contribute--docs#proposal-decisions).
