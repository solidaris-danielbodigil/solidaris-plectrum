Plectrum is the Solidaris design system — shared Angular components, tokens and layout classes for every application.

Packages are unreleased (`0.1.0`) and are not on a registry yet. Until the first release lands in [What's new](?path=/docs/docs-what-s-new--docs), install **packed tarballs**. [Use Plectrum in an app](?path=/docs/get-started-use-plectrum-in-an-app--docs) has the install command for each case.

Start by installing the packages and rendering one Core component. Then pick the next component or token from the catalogues.

<Unstyled>
  <Story of={Figures.FirstHour} />

Core components are maintained for reuse across Solidaris applications. Candidate and App-specific work stays with an application team until the core team promotes it. Every component page shows **status** and **owner** — definitions: [Contribute → Status and owner](?path=/docs/get-started-contribute--docs#status-and-owner).

Design and support: [Figma UI Kit](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-?node-id=6961-92390) · [Plectrum on zeroheight](https://zeroheight.com/5cba76f64/p/8028d1-plectrum-design-system) · [Token finder](?path=/docs/foundations-token-finder--docs) · [Component status](?path=/docs/docs-component-status--docs)
