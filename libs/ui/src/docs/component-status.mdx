# Component status

Every Angular component in `libs/ui` with its governance status, owner and the components that depend on it — the living index from `.ai/contracts/index.json` (regenerated by `npm run generate-index`, CI-gated). Names link to the component's docs page; the PrimeNG components a `pds-*` component wraps are named on that page. CSS-only blocks stay on their own pages; they are not Angular components and do not appear here. Status definitions: [Contribute → Status and owner](?path=/docs/get-started-contribute--docs#status-and-owner).
