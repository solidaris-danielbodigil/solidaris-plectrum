# Troubleshooting

Known failure modes and their causes — check here before debugging from scratch.

## Components look unthemed

<DocsTable
  headers={['Symptom', 'Cause', 'Fix']}
  rows={[
    ['PrimeNG components render unstyled', 'providePlectrum() missing from the application config', 'Add it to providers — every --p-* custom property exists only after the theme boots'],
    ['Colors fine before bootstrap, PrimeNG chrome wrong after', 'Hybrid tokens fall back to generated literals; the live preset overrides them', 'Expected — check the preset version (v0.6 default) via resolvePresetVersion()'],
    ['A --pds-* token resolves to nothing', 'Token missing from 01-settings, or a typo — unknown names fail tokens:lint', 'Find the real name on Foundations pages or the Token finder'],
  ]}
/>

## Storybook

<DocsTable
  headers={['Symptom', 'Cause', 'Fix']}
  rows={[
    ['GitHub Pages iframe 404s', 'Absolute STORYBOOK_PUBLIC_PATH becomes .//repo/storybook/…', 'Keep STORYBOOK_PUBLIC_PATH=./ (wired in main.ts) — never the full subpath'],
    ['Unable to index files / of={} path (exist?)', 'Storybook cached a failed re-index after HMR and will not retry until the process restarts', 'Stop and run npm run storybook again, then hard-refresh the browser'],
    ['Deleted story still in the sidebar', 'Windows file watcher can miss unlink events', 'Recreate the file, save, delete it again — or restart Storybook'],
    ['Manager theme edits not applied', 'The manager bundle is cached', 'Restart storybook; hard-refresh the browser'],
    ['Interactions / Accessibility panels missing', 'Docs view mode — the panels only exist in story view', 'Open the individual story in the sidebar'],
  ]}
/>

## CI gates

<DocsTable
  headers={['Failing step', 'Meaning', 'Fix']}
  rows={[
    ['tokens:build + git diff', 'Generated SCSS or tokens.generated.ts stale', 'Run npm run tokens:build and commit the generated files'],
    ['generate-index + git diff', '.ai/contracts/index.json stale', 'Run npm run generate-index and commit — pds:component and the editor hook normally do this'],
    ['tokens:check-prefix', 'New bare --spacing-/--text-/--font- declaration', 'Declare the token as --pds-* (bare names are legacy aliases only)'],
    ['tokens:lint', '--p-* outside 01-settings, or unknown --pds-* name', 'Move the bridge to _settings.{component}.scss; fix the token name'],
    ['npm ci fails on lockfile', 'package-lock.json written by a different npm major', 'Regenerate the lockfile with npm 10 (the version CI uses)'],
    ['pack:smoke', 'Published packages cannot back a consumer app', 'Check package exports and the styles includePaths contract'],
  ]}
/>
