# Process and contracts

This page reads the shared process contract, team registry and compatibility declaration. The installed toolkit renders `plectrum help` and its agent guidance from the same process contract, so a changed step or command reaches all three together.

This is the reference for **who acts, what evidence is required and which command runs where**. For token values and their Figma sync, see [Token pipeline](?path=/docs/docs-token-pipeline--docs). For CI and release tasks, see [Maintainer workflow](?path=/docs/docs-maintainer-workflow--docs).
