# Process and contracts

> **In short.** The reference behind [Contribute](?path=/docs/get-started-contribute--docs): each journey step by step, who runs it, and the command for each step — `npm run` in the Plectrum repository, `plectrum` in an application. Everything here is rendered from `process.json`, the same file the CLI and the agents read.

Who does what, and which command runs where. `plectrum help` and the agents use the same process. Application setup: [Build with Plectrum](?path=/docs/get-started-use-plectrum-in-an-app--docs). Token sync: [Token pipeline](?path=/docs/docs-token-pipeline--docs). CI and releases: [Maintainer workflow](?path=/docs/docs-maintainer-workflow--docs).
