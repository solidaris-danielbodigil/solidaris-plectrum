# Build with Plectrum

An application team installs versioned packages, initializes the matching toolkit in its own repository and consumes CSS custom properties. No token values are copied and no Plectrum folder is copied into the application.

## Initialize the team toolkit

Run from the **application repository root**, with your registered team and application IDs.

<Unstyled>
  <Story of={Figures.Initialize} />
</Unstyled>

In Cursor, select the generated **Plectrum** agent; in VS Code, select **Plectrum** in the chat agent picker. Rules, process, schemas and the offline catalogue live in the installed toolkit. Set Figma or Storybook MCP URLs in `.plectrum/config.json`; a published Storybook page is not an MCP server.

The Storybook **Preset** control (`v1` / `v0.6`) switches the theme inside this catalogue. It is not the package version. `providePlectrum()` with no argument uses preset v1. Moved from a 0.x preset? Find every renamed input on [What's new](?path=/docs/docs-what-s-new--docs).

## Fonts, icons and browsers

Agenda ships as four `.woff2` files at `libs/assets/fonts/agenda` in the design-system repository. Copy that folder into your app's own assets, and add it to `angular.json` so `/assets/fonts/agenda/*.woff2` resolves.

Open Sans is not bundled. Load it yourself — a font service link or a self-hosted package both work — and make sure it is available before your app renders.

Install `bootstrap-icons`, then add `node_modules/bootstrap-icons/font/bootstrap-icons.css` to the `styles` array in `angular.json`.

This app supports what Angular supports by default: current Chrome, Edge, Firefox and Safari, desktop and mobile. Add your own browser list only if you must support something older.

## Wire the stylesheet

`angular.json` — resolve the ITCSS source from the package:

<pre><code>{`"stylePreprocessorOptions": {
  "includePaths": ["node_modules/${PACKAGE_NAMES.styles}/src"]
}`}</code></pre>

`src/styles.scss` — the whole system is one `@use`:

```scss
@use '01-settings/settings.prefix' as *;
@use 'main';
```

## Boot the theme

<pre><code>{`// src/app/app.config.ts
import { ApplicationConfig, provideZoneChangeDetection } from '@angular/core';
import { provideAnimationsAsync } from '@angular/platform-browser/animations/async';
import { providePlectrum } from '${PACKAGE_NAMES.plectrum}';

export const appConfig: ApplicationConfig = {
  providers: [
    provideZoneChangeDetection({ eventCoalescing: true }),
    provideAnimationsAsync(),
    providePlectrum(),
  ],
};`}</code></pre>

`providePlectrum()` registers the PrimeNG theme and emits every `--p-*` custom property. The generated `--pds-*` tokens fall back to literals, so styles render even before the theme boots — but PrimeNG components need the provider.

## First component

The sample application renders one Core component around one PrimeNG input. This is `tools/packaging/consumer-app/src/app/app.ts` with the `pInputText` directive added so the PrimeNG theme visibly applies:

```ts
// src/app/app.ts
import { Component } from '@angular/core';
import { InputText } from 'primeng/inputtext';
import { FormFieldComponent } from '@solidaris-danielbodigil/pds-ui';

@Component({
  selector: 'app-root',
  imports: [FormFieldComponent, InputText],
  template: `
    <pds-form-field
      label="Member number"
      inputId="member"
      hint="Ten digits, no spaces"
      requiredLabel="obligatoire"
    >
      <input pInputText id="member" type="text" autocomplete="off" />
    </pds-form-field>
  `,
})
export class App {}
```

`ng serve` shows a labelled, themed field: the label and hint come from `pds-form-field` ([Form Field](?path=/docs/custom-components-form-field--docs)), the input chrome from the Plectrum preset. Every Core Angular component is exported from the UI package root — the component's docs page names the class to import.

PrimeNG components use the Plectrum preset as-is ([theme gallery](?path=/docs/primeng-actions--docs)). [Find a component](?path=/docs/start-here-catalogue--docs) lists each Core component. Layout with `o-flex` / `o-layout`, chrome with `u-*`, values via `var(--pds-*)`.
