## Deliberately stock

No scoped `--p-*` / `.p-*` overrides exist for button, stepper, tag (beyond the icon line-height), inputs, drawer chrome, dialog, popover, or menu — and none should be added (rule `09-styling-policy.md` §7). No `styleClass` on `p-drawer` / `p-dialog` roots; overlays inside flex or clipped layouts use `appendTo="body"`.

## Maintenance

- New bridge → `01-settings/_settings.{primeng-component}.scss`, scoped to the BEM wrapper, plus a row here.
- New structural restyle → `06-components` with a justification comment, plus a row here and a story.
- The [Token contracts](?path=/docs/foundations-token-contracts--docs) page verifies `--p-*` mappings recorded in component metadata against the compiled CSS.
