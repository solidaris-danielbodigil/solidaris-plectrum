# Profile Drawer

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

iSHARE “Carte affilié” detail drawer — a headless `p-drawer` wrapper.

## When to use

- A slide-in profile detail overlay from an overview card
- Read-only identity, contact, related people, and notes
- A Détails / Documents view switch on the same surface

## When not to use

- An always-visible panel — use a static column
- Editing the record in place — open a dedicated form from the actions

## Accessibility

- Copy, menu, close, and family arrows have `aria-label`s
- Sections use `aria-labelledby` on their heading ids
- Bullet separators and dividers are `aria-hidden`
- `p-drawer` owns the focus trap and Escape
- Sensitive note tags pair an icon with visible label text — not colour alone
