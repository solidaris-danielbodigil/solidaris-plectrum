# Plectrum Avatar

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

Initials-based and illustrated identity avatar for the Plectrum design system. Not the same as PrimeNG Avatar — this is a custom Plectrum treatment.

## When to use

- User initials avatar or profile chip
- Small identity marker in navigation or lists
- Large illustrated identity next to a profile title

## When not to use

- Generic photo avatars — this treatment is initials or catalog illustration only
- Nesting a second interactive avatar inside a button without `focusable="false"` — the trigger already has the name

## Accessibility

- Focusable (default): `role="img"` and `aria-label` (or the initials)
- Decorative inside another control: set `focusable="false"` so the host is `aria-hidden`
- Illustration and initials glyphs are `aria-hidden` — the host label is the accessible name
- Hover, focus-visible, and pressed are CSS pseudo-classes; `state` is the persistent selected halo
