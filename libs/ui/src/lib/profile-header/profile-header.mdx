## With slots

The full Figma composition. The icon actions, action buttons, A-valoir panel, tabs and view switch are example content projected into `[slot=actions]`, `[slot=aside]`, `[slot=nav]` and `[slot=nav-end]` — the application owns them. The A-valoir panel is a PrimeNG Card: the header's own Card bridges do not reach it, so it keeps the theme look. With tabs in `[slot=nav]` the tablist border is the bottom edge and the header drops its own.

## Single status menu item

Exactly one `menuItems` entry: no SplitButton — the plain Button stands for that item, runs its `command` and emits `statusMenuSelect`.

<Canvas of={Stories.SingleStatusMenuItem} />

## Multiple status actions

More than one `menuItems` entry: a SplitButton with the action count. The main button and the chevron both open the menu; `statusMenuSelect` reports the enabled item chosen. When the menu closes, focus returns to the half that opened it.

<Canvas of={Stories.MultipleStatusActions} />

## Disabled status

`statusAction.disabled` keeps the status visible but inert.

<Canvas of={Stories.DisabledStatus} />

## Disabled status actions

With several `menuItems`, `disabled` turns off both halves of the SplitButton — no menu opens.

<Canvas of={Stories.DisabledStatusActions} />

## Info tag filters

Tags with a `filterKey` are PrimeNG ToggleButtons, one pressed at a time — the pressed one also shows a check icon. The last tag has no `filterKey` and stays a display-only Tag.
