# Nav Shell

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

First-level navigation shell — vertical sidebar for the Solidaris ecosystem.

## When to use

- App-wide first-level navigation
- Collapsed icon-only sidebar that expands on hover or focus
- An ecosystem app switcher passed as generic `[items]`

## When not to use

- Hardcoding routes inside the component — pass items from the app
- Second-level navigation inside this shell — pair with Sub Nav Shell

## Accessibility

- Landmark navigation with an accessible name on each link (`aria-label` from the item)
- Active item sets `aria-current="page"`
- Logo is `aria-hidden` — it is not a link
- Expand is CSS `:hover` / `:focus-within` so keyboard focus reveals labels
- Tab / Shift+Tab move between items; Enter / Space activate the focused link

## Figma

[Plectrum for PrimeNG (Main) node 1:1433](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-?node-id=1-1433). [Custom components node 18:6419](https://www.figma.com/design/IRkr21rHS0w7rI0bgrv1fZ/PLECTRUM-·-Custom-components?node-id=18-6419) is the iCRM Audit reference.

- **Collapsed** (default): icon-only; width follows the icon column + padding
- **Expanded**: revealed on `:hover` / `:focus-within` (CSS only) — labels + wordmark fade in via a discrete `display` transition and the panel grows to its widest item. Overlays content — no document-flow push.
- No PrimeNG equivalent; uses semantic `<ul>` with ARIA attributes.
- Generic API — pass any items via `[items]`. No app-specific logic inside the component.
