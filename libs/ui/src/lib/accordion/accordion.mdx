# Accordion

PrimeNG `p-accordion` with the Plectrum theme. Certificate and audit panels add **`c-accordion--bordered`** — a BEMIT modifier already in `libs/styles`. There is no Angular wrapper and no `[border]` input. Put the class on `p-accordion`.

Figma: [iSHARE-Audit — bordered accordion](https://www.figma.com/design/9HlAudLC1oesvT8IkrmR6I/iSHARE-Audit?node-id=544-6474)

Constraints:

- PrimeNG owns expand / collapse and the `.p-accordion*` DOM.
- Plectrum owns stock `--p-accordion-*` via `providePlectrum()`.
- `c-accordion--bordered` owns the card-like stack: token bridges in `01-settings/_settings.accordion.scss`, stacked radii in `06-components/_components.accordion.scss`.
- Do not override `.p-accordionpanel` with hardcoded hex or `!important`.

How to write a story for a layer like this: [Writing stories](?path=/docs/docs-writing-stories--docs).
