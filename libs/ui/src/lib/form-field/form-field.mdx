# Form Field

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

Optional field shell with a custom static label (not PrimeNG FloatLabel), optional helper text, required asterisk, invalid label colour, and a built-in `p-message` error slot.

Parent forms should pass `[invalid]="isFieldInvalid(form, 'controlName')"` where `isFieldInvalid` checks `control.invalid && (control.touched || control.dirty || form.submitted)` — SelectButton and similar controls set `dirty` but not `touched` on click.

## When to use

- Static labels above or beside PrimeNG inputs
- Horizontal label + control rows that share one invalid colour
- A required marker and a `p-message` error under the control

## When not to use

- PrimeNG FloatLabel when the design calls for a static muted label
- Horizontal layout without a matching `inputId` / control `id` — the label cannot associate
- Clearable `pInputText` with `type="search"` — native clear conflicts with `pds-input-clear`

## Accessibility

- Associate the label with the control by passing the same `inputId` as the control `id` (`<label for>`)
- When `inputId` is omitted, the label still has a generated `id` that a control can reference with `aria-labelledby`
- Give the hint and error stable ids and set `aria-describedby` on the projected control so assistive tech announces helper and error text
- Required: the visible asterisk is `aria-hidden`; a visually hidden `requiredLabel` is announced. Also mark the control `required` / `aria-required`
