## Use in an application

Copy this into the application. It imports `FormFieldComponent` from `@solidaris/ui` and `InputText` from PrimeNG. The canvas below is the same component running inside Storybook; its Show code panel is this snippet, not the story file.

```ts
import { Component } from '@angular/core';
import { InputText } from 'primeng/inputtext';
import { FormFieldComponent } from '@solidaris/ui';

@Component({
  selector: 'app-root',
  imports: [FormFieldComponent, InputText],
  template: `
    <pds-form-field
      label="Member number"
      inputId="member"
      hint="Ten digits, no spaces"
      requiredLabel="obligatoire"
    >
      <input pInputText id="member" type="text" autocomplete="off" />
    </pds-form-field>
  `,
})
export class App {}
```

`requiredLabel` is the word a screen reader hears after the asterisk. Use `obligatoire` in French examples and `verplicht` in Dutch examples. Pass the same language as the label and the error.

The sample app at `tools/packaging/consumer-app` builds this snippet in CI (`npm run pack:smoke`).
