# Transactions CICS Modal

<Unstyled>
  <Story of={Stories.Status} />

Legacy iSHARE Transactions CICS modal — searchable list with per-row CICS launch CTA (Scenario 4).

## When to use

- Launching legacy CICS transactions from an affiliate dossier

## When not to use

- A generic data-table dialog — compose `p-dialog` + `p-table` directly
- Screens outside iSHARE — the row model is CICS code, description, and launch URL

## Accessibility

- Dialog role and focus trap come from PrimeNG `p-dialog`
- Escape closes; Tab cycles the search field and table
- Search has an `aria-label`; column headers use `scope="col"`
- Each launch control has a visible CICS label plus an external-link icon that is decorative

## Figma

There is no Plectrum UI Kit node. Stock Dialog and Table live in [Plectrum for PrimeNG (Main)](https://www.figma.com/design/YNZ1DlSjDNUXrvkxlSp10D/Plectrum-for-PrimeNG--Main-). This page documents the iSHARE CICS content pattern.
