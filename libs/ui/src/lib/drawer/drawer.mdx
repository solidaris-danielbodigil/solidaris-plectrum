# Drawer

`c-drawer` is the headless shell vocabulary for PrimeNG drawers: features render inside `p-drawer`'s `#headless` template using these element classes plus object-class mixes. There is no generic Angular wrapper — the block keeps shared chrome consistent while every feature owns its content.

- **PrimeNG**: `p-drawer` — always `appendTo="body"` inside flex or clipped layouts; no `styleClass` on the root (rule 09 §11)
- **Styles**: `libs/styles/src/06-components/_components.drawer.scss`; width tokens in `_settings.drawer.scss` (`--pds-size-drawer-min-width` / `--pds-size-drawer-max-width`, `width: max-content`)
- **Helpers**: `PDS_DRAWER_APPEND_TO`, `PDS_DRAWER_CONTENT_STYLE`, `DrawerPosition`, `DetailListRow` from `libs/ui/src/lib/drawer`
- **Real integration**: [Affiliate Detail Drawer](?path=/docs/custom-components-affiliate-detail-drawer--docs)
