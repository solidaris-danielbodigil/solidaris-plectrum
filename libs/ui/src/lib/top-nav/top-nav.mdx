# Top Nav

<Unstyled>
  <Story of={Stories.Status} />

Application shell header bar.

## When to use

- Application shell top bar
- Breadcrumb-driven page context with utility actions
- Inline search that expands from an icon

## When not to use

- Parsing router state inside Top Nav — pass `[breadcrumbs]` from the shell
- Letting Top Nav own Sub Nav Shell state — bind `subNavExpandedChange` in the parent

## Accessibility

- Sub-nav toggle uses `aria-pressed` and optional `aria-controls`
- Search icon uses `aria-expanded` / `aria-controls`; the field is `role="searchbox"`
- Help and avatar menu triggers have accessible names; avatar inside a menu button is `focusable="false"`
- Breadcrumb has an `aria-label` on `p-breadcrumb`

## Figma

[Custom components node 1:1533](https://www.figma.com/design/IRkr21rHS0w7rI0bgrv1fZ/PLECTRUM-%C2%B7-Custom-components?node-id=1-1533)

- Breadcrumb data is passed in via the `breadcrumbs` input; the component does not derive routes itself
- Sub-navigation state is controlled via `subNavExpanded` / `subNavExpandedChange`
- The search icon expands into a PrimeNG `IconField` + `InputText` control
- Buttons use the PrimeNG text variant and keep hover / focus-visible / active states in CSS
