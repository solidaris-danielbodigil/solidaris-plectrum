# Sub Nav Shell

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

Second-level navigation sidebar. Child of `NavShellComponent` — opens when a nav-shell item is clicked.

## When to use

- Second-level navigation alongside Nav Shell
- Module-level grouped menu with collapsible accordion sections

## When not to use

- Standalone full-page navigation — this is a sidebar companion, not a page nav
- First-level app switching — that belongs on Nav Shell

## Accessibility

- Accordion headers expose expand / collapse; items are links or buttons with visible labels
- Disabled items stay visible at reduced opacity and are not interactive
- Badge counts must not be the only indication of status — keep the item label
- Footer changelog is a text link; hide the whole footer when there is no version

- A heading header with the module/app title
- Optional featured items (sections without a label) rendered above the accordion
- Collapsible grouped sections using PrimeNG Accordion (`p-accordion`)
- Menu items with optional leading icon and PrimeNG Badge (`p-badge`) counter
- A version/changelog footer
