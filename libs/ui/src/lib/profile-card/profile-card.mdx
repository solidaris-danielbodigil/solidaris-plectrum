# Profile Card

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

iSHARE affiliate audit summary card — card gradient is driven by `statusAction.severity`; the `variant` input is a fallback when no status action is set.

## When to use

- A single-person profile summary after lookup
- Status-driven overview with identifiers, info tags, and a primary action

## When not to use

- A full-page form — this card is a read-only summary
- A table of many people — identifier chips are a single snapshot

## Accessibility

- Loaded: `aria-labelledby` on the article points at the title or title-action
- Loading: `aria-label` + `aria-busy` on the article; skeleton lines are `aria-hidden`
- Info-tag options expose `aria-pressed`; copy chips use `Copier {label}`
- Status and tags must include visible label text — not colour alone
- Optional Alt+A primary-action shortcut (`aria-keyshortcuts`) is skipped in editable fields
