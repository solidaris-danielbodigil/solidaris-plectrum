# Delay Prediction Card

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

Prédiction du délai. In iSHARE document detail, the section title **Prédiction du delai** is rendered outside this card (same style as **Détails**).

## When to use

- Document detail sidebar — predicted processing delay
- Dossier follow-up panels that show days remaining and a close date

## When not to use

- A generic KPI tile — compose a `p-card` with tokens instead
- Screens outside iSHARE — this card is app-owned delay-prediction semantics

## Accessibility

- The card is an `article` with a region `aria-label`
- The overflow control has an `aria-label`; the warning icon is `aria-hidden`
- Days and date labels are visible text next to their values — not colour alone
