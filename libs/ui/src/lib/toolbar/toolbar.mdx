# Toolbar

<Unstyled>
  <Story of={Stories.Status} />
</Unstyled>

`pds-toolbar` is a sticky-capable action row on a `p-card` surface with two named slots. Layout inside the card is entirely `o-flex` / `o-layout` mixes — the SCSS owns only the sticky position and the wrap constraint.

## When to use

- Filter and search row above a list or table
- Sticky page-level action bar inside a scroll container

## When not to use

- Application navigation — use Top Nav / Nav Shell
- Putting page-specific chrome into the shared block — add a domain BEM class on the host instead

## Accessibility

- Slot content keeps its native tab order
- Search, filters, and actions must carry their own accessible names
- Sticky position does not create a landmark — wrap the page region in the app if one is needed

## Figma

There is no Plectrum UI Kit node for the generic toolbar. [iSHARE-Audit node 324:5772](https://www.figma.com/design/9HlAudLC1oesvT8IkrmR6I/iSHARE-Audit?node-id=324-5772) is reference usage for the documents filter row (`c-affiliate-documents-toolbar`).

- **PrimeNG**: wraps `p-card`
- **BEM block**: `c-toolbar` (host) — `c-toolbar--sticky` bound to the `sticky` input
- **Styles**: `libs/styles/src/06-components/_components.toolbar.scss`
- **Domain variants**: apply a domain BEM class on the host for page-specific chrome — e.g. `c-affiliate-documents-toolbar` on the iSHARE documents toolbar
