# Layout

## How a page adapts

Start from the narrow screen. The column is the default.

- A side navigation hides until `md`, then becomes a column beside the content (`o-layout--hidden` and `o-layout--block@md`).
- Page padding grows with the screen: `o-layout--padding-3` then `o-layout--padding-4@md`.
- A two-column form becomes one column by stacking. Do not keep two columns if the labels no longer fit.
- A data table scrolls inside its region (`o-layout--overflow-x-auto`). Do not shrink the type to make the columns fit.

Add these classes in the HTML, next to `o-flex`. Do not write spacing in the component stylesheet.

Breakpoints are mobile-first: `sm` (48rem) · `md` (62rem) · `lg` (75rem) · `xl` (87.5rem). In a media query, `rem` uses the browser’s initial 16px root, so `sm` is 768px wide. Spacing inside the page still uses the 14px type root.

Six categories: Dimensions, Overflow, Display, Position, Sticky, Spacing — one section each below, full class list in [API](#api).

Styles: `libs/styles/src/05-objects/layout/_objects.layout.scss`. Rule: `.ai/rules/08-object-classes.md`.

## Full height

`.o-layout--full-height` sets `height: 100%`. In order to use a vertical grid with `.o-flex--col`, its ancestor needs to have a height set. As fixing a container's height is not recommended, `.o-layout--full-height` will set it to a relative value.

`.o-layout--full-height` needs to be added to **all** `.o-flex__item` ancestors until a container with a height is reached, or up to the `html` tag.

```html
<html class="o-layout o-layout--full-height">
  <body class="o-layout o-layout--full-height">
    <main class="o-layout o-layout--full-height">
      <div class="o-flex o-flex--col o-layout o-layout--full-height">
        <div class="o-flex__item"></div>
      </div>
    </main>
  </body>
</html>
```

## Overflow

Overflow syntax: `.o-layout--overflow-[axis?]-[value]`

**Axes:** shorthand (`overflow-{value}`), `overflow-x-{value}`, `overflow-y-{value}`

Every overflow class takes a `@{breakpoint}` variant. The API table below lists every value.

```html
<div class="o-layout o-layout--overflow-hidden o-layout--overflow-auto@md">...</div>
<div class="o-layout o-layout--overflow-x-hidden o-layout--overflow-y-auto">...</div>
```

## Display

Display classes control the `display` property with responsive support — full list in [API](#api).

`.o-layout--grid` only sets `display: grid`. For a column system (equal cols, span, alignment), use **`.o-flex`** — see [Foundations / Flex Grid](?path=/docs/foundations-flex-grid--flex-grid).

```html
<aside class="o-layout o-layout--hidden o-layout--block@md">Sidebar</aside>
<div class="o-layout o-layout--block o-layout--grid@lg">...</div>
```

## Spacing

Spacing classes apply gap, padding, or margin from the [spacing scale](?path=/docs/foundations-spacing--docs).

```html
<div class="o-layout o-layout--{property}-{scale}"></div>
```

**Properties:** `gap` `row-gap` `column-gap` `padding` `padding-top` `padding-right` `padding-bottom` `padding-left` `padding-inline` `padding-block` `margin` `margin-top` `margin-right` `margin-bottom` `margin-left` `margin-inline` `margin-block`

The API table below lists the scale.

```html
<div class="o-flex o-layout o-layout--gap-2 o-layout--gap-4@md">...</div>
<div class="o-layout o-layout--padding-2 o-layout--padding-4@lg">...</div>
```

Or reuse the variables in SCSS:

```scss
padding: var(--pds-spacing-2) var(--pds-spacing-1-5) var(--pds-spacing-0) var(--pds-spacing-2);
```

## Responsive

All layout modifiers support responsive variants using the `@{breakpoint}` suffix.

Pattern: `.o-layout--{modifier}@{breakpoint}`

The responsive class applies from that breakpoint **upward** (mobile-first, `min-width`). Resize the viewport to see the demo change.

```html
<div class="o-flex o-layout o-layout--gap-1 o-layout--gap-2@sm o-layout--gap-4@lg">...</div>
<aside class="o-layout o-layout--hidden o-layout--block@md">Sidebar</aside>
<div class="o-layout o-layout--overflow-y-auto o-layout--overflow-y-visible@lg">...</div>
<header class="o-layout o-layout--static o-layout--sticky@md" style="top: 0;">Nav</header>
```
