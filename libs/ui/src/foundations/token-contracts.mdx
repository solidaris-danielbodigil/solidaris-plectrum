# Token contracts

Each component lists the tokens it uses in its `.metadata.ts`, and each one is checked against the compiled stylesheet. A **not declared** row means the metadata names a token that does not exist: fix the list or add the token.

In an application, `plectrum tokens check` does the equivalent check on your sources — see [Build with Plectrum → Validate](?path=/docs/get-started-use-plectrum-in-an-app--docs#validate).

How metadata, the generated index and protocols fit together: [How agents work](?path=/docs/docs-ai-strategy--docs).
