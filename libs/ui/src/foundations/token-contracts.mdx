# Token contracts

Every component declares the tokens it consumes in its `.metadata.ts`. Each row is checked against the compiled stylesheet, so a **not declared** row is a broken contract — the component references a token that no longer exists.

How metadata, the generated index and protocols fit together: [AI strategy](?path=/docs/docs-ai-strategy--docs).
