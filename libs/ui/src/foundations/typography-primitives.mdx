# Typography primitives

Families, sizes, weights, line-heights and letter-spacing. These exist to author a semantic role in `_settings.typography-semantic.scss` — reach for a [role](?path=/docs/foundations-typography-roles--docs) in components instead.

## How to use

1. Compose a new role from these primitives in `01-settings`.
2. Export the role as a mixin in `02-tools` and a `u-text-*` utility.
3. Components include the mixin. They do not pick a size and a line-height independently.

Base is `1rem = 14px`. Plectrum type is untracked (`letter-spacing: 0`).
