# Spacing

Scale from `--pds-base-unit` (`1rem = 14px`). The step unit is `--pds-spacing-unit` — half the base unit (`0.5rem` = 7px). Whole-number stops are that many units: `spacing-1` is one unit, `spacing-2` is two (`1rem`). Each bar below is the live token width.

In templates write `o-layout--gap-2` or `o-layout--padding-3`. Use `var(--pds-spacing-*)` only when defining a component token in `01-settings`. See [Foundations / Layout](?path=/docs/foundations-layout--docs#spacing) for the object-class surface.

## Examples

```html
<!-- template — spacing lives on object classes, not in component SCSS -->
<div class="c-card o-flex o-flex--col o-layout--gap-2 o-layout--padding-3">
  …
</div>
```

Below one unit the scale has three fractional stops — `0-25`, `0-5` and `0-75` (0.25, 0.5 and 0.75 of a unit) — and `1-5` between one and two. A class suffix writes the decimal as a dash: `1-5` is 1.5 units. `0-75` exists for icon + label gaps; the others for hairline offsets and control padding. `auto` is for margin centring only — `gap` and `padding` do not accept it, so the [Playground](?path=/story/foundations-spacing--playground) never offers it there.

Declared in `_settings.spacing.scss`. Classes: `.o-layout--{gap|padding|margin}-{step}`. Click a step to copy it.
