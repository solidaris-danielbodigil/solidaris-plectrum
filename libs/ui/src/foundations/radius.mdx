# Radius

Corner radii come straight from Figma `border/radius/*`. Values are unmapped literals — no PrimeNG alias — so they are identical before and after bootstrap. Each preview shows the real corner at the token value.

Use a named stop; the preview shows the real corner.

For utilities and per-edge targets see [Foundations / Borders](?path=/docs/foundations-borders--docs).

## How to use

1. Use the `u-radius-*` utility when rounding a demo or one-off box.
2. In a component, point a component token at a stop: `--pds-radius-card: var(--pds-radius-lg)`.
3. Per-edge and per-corner targets exist: `u-radius-top-lg`, `u-radius-top-start-xl`.

Declared in `_settings.radius.generated.scss` and `_settings.radius.scss`. Classes: `.u-radius-{stop}` · `.u-radius-{side|corner}-{stop}`. `2xl` and `pill` are code-owned extras; the rest come from Figma.
