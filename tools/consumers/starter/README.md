# Plectrum application starter

Copy this folder into a new repository. Set `plectrum.team`, `plectrum.application` and `plectrum.repository` in `package.json` before running `npm install`. Configure developer access to the Solidaris GitHub Packages registry outside this repository; `.npmrc` contains only the registry URL. Grant the new GitHub repository read access to the private packages so its generated workflow can install them with `GITHUB_TOKEN`. `npm install` runs the application-owned `postinstall` to generate ITCSS, Storybook, `.ai` guidance, Git hook and CI. Commit those generated files and the lockfile. If npm scripts are disabled, run `npm run pds:bootstrap` afterward.

If Solidaris policy requires Nexus, have DevOps make all four packages available through its approved repository and replace the scoped `.npmrc` URL with that endpoint. Check the effective value with `npm config get @solidaris-danielbodigil:registry`. An `UNABLE_TO_GET_ISSUER_CERT_LOCALLY` error is a certificate-trust failure at the endpoint or proxy Node actually reached; the scope mapping alone cannot fix it. Ask DevOps for the approved CA bundle or Node trust configuration for both local machines and CI. Keep TLS verification enabled.

Run `npm start`, `npm run pds:storybook`, `npm run pds:test:unit`, `npm run pds:test:stories`, `npm run pds:build-storybook` and `npm run pds:check:ci` to verify the application. Local Storybook gets FR/NL locale and preset controls from the generated preview; v1 is the default and deprecated v0.6 is retained for migration comparisons. A local component starts with `npm run pds:component -- --name my-component` and does not wait for Core approval. Both test runners use Chromium; run `npx playwright install chromium` once locally (CI installs it in its job).

`package.json` pins the Plectrum versions. Install them only once that release appears in the [release history](https://github.com/solidaris-danielbodigil/solidaris-plectrum/releases); until then, validate with local tarballs. The first install also needs registry credentials, which this starter does not contain.
